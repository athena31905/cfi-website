Digital Forensics

We investigate reliable methods for identifying, collecting, and analyzing digital evidence. Our research focuses on hidden data detection, digital evidence search and indexing, e-Discovery, and malware analysis to support efficient and reliable forensic investigations.

  • Cloud Forensics
  • Mobile & IoT Forensics
  • AI-Driven Digital Forensics
  • Malware & Ransomware Forensics
  • Anti-Forensics & Evidence Integrity

5G/6G Security

At CFI, we advance security research for 5G and emerging 6G networks, with a focus on edge, cloud-native, and industrial IoT environments. Our work builds on MEC threat analysis, 5G open-source platforms, testbed-based network traffic analysis, and AI-based intrusion detection to improve the security and resilience of next-generation communication systems.

  • AI-Driven 5G/6G Security
  • Network Slicing Security
  • O-RAN & Zero-Trust Security
  • Post-Quantum Mobile Security
  • 6G Physical-Layer Security

Post-Quantum Security

Post-quantum security is essential for transitioning digital systems away from quantum-vulnerable cryptography. Our research focuses on cryptographic visibility and agility to support efficient PQC migration, while accelerating post-quantum algorithms on FPGA platforms for high-performance deployment.

  • Cryptographic Visibility & Risk Assessment
  • Crypto-Agility & PQC Migration
  • Hybrid Post-Quantum Security
  • FPGA-Based PQC Acceleration
  • PQC Hardware Security & Validation

Space Security

We conduct security research for satellite communication networks, with a focus on LEO constellations and integrated space–terrestrial systems. Our research analyzes communication architectures, user and control data flows, trust boundaries, and cyber threats across satellite terminals, payloads, inter-satellite links, gateways, and ground systems. We also develop testbed-based methods to evaluate secure data transmission, authentication, protocol security, and the reliability of satellite communications.

  • LEO Satellite Network Security
  • Satellite Communication Threat Analysis
  • User & Control Data Security
  • CCSDS & Space Protocol Security
  • Secure Space–Terrestrial Networks
