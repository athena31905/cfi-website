Secure Admin Portal

Add, edit, archive, or delete publication records through a Google-account protected Apps Script portal connected to Google Sheet storage.

No admin ID or password is stored in this HTML. The admin portal verifies the signed-in Google account on the server side, checks it against an allowlist, and writes approved records to the connected Google Sheet.
Sheet-backed storage

When the public API is configured, Sheet records become the source of truth. Deleted Sheet records disappear from the public archive.

Edit/delete ready

The portal lists Sheet records with Edit and Delete actions, while public visitors only receive published records.

Configure PUBLIC_DATA_ENDPOINT_URL and ADMIN_PORTAL_URL in the script section before publishing.
